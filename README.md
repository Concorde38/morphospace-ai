
# MORPHOSPACE-AI

## Overview:

MORPHOSPACE-AI is a computational oncology project
that integrates histopathology images and spatial
transcriptomics using machine learning.

## Research Question

Does spatial context improve the prediction of
molecular programs from H&E histopathology images?

## Research Objectives

1. Process ovarian cancer spatial transcriptomics data.
2. Extract morphological features from H&E images.
3. Develop machine learning and graph neural network models.
4. Evaluate model performance and interpretability.
5. Investigate the role of spatial tissue organization.

## Models

-M0: Ridge Regression
-M1: Multilayer Perceptron (MLP)
-M2: Spatial Graph Neural Network (GraphSAGE)
-M3: Distance-aware Graph Neural Network
